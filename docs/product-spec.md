# MANDRONG 제품 명세

## 제품 정의

만드롱(MANDRONG)은 디자인 도구를 다루지 않는 요식업 자영업자가 메뉴 사진, 홍보 문구, 매장 정보, 원하는 분위기만 입력해 포스터, 배너, 메뉴판, SNS 홍보 이미지를 생성하고 수정, 재구성, 다운로드하는 웹 서비스다.

사용자는 레이어, 폰트, 정렬, 개별 요소 편집을 직접 다루지 않는다. 생성물에 문제가 있으면 포스트잇 형태의 메모를 붙이고, 서버가 원본 이미지, 선택 영역, 수정 메모를 OpenAI `gpt-image-2`에 전달해 새 버전을 만든다.

## 대상 사용자

- 디자인 작업 경험이 적은 요식업 자영업자
- 빠르게 매장 홍보물을 제작해야 하는 점주 또는 직원
- 메뉴 사진과 가격 정보는 가지고 있으나 포스터 구성, 배치, 색상 선택에 익숙하지 않은 사용자

## 핵심 가치

- 한 화면에서 한 가지 행동만 수행한다.
- 생성된 홍보물이 항상 가장 중요한 화면 요소다.
- 사용자는 세부 편집 대신 의도와 수정 요청을 자연어로 전달한다.
- 모든 생성, 수정, 재구성 결과는 버전 히스토리로 보관한다.
- OpenAI API 키와 호출 로직은 FastAPI 서버에만 존재한다.

## 범위

### 포함

- 홍보물 용도와 크기 선택
- 자유 문구 입력
- 메뉴 사진 업로드 및 선택
- 매장 정보 입력 및 선택
- 분위기 선택 및 참고 디자인 이미지 업로드
- `gpt-image-2` 기반 이미지 생성
- 포스트잇 메모 기반 수정 요청
- 수정 전후 비교
- 다른 비율로 재구성
- PNG, JPEG, PDF 다운로드
- 프로젝트, 생성 결과, 수정 버전, 내보내기 히스토리 저장

### 제외

- 전문 디자인 편집기 수준의 레이어 편집
- 요소별 폰트, 색상, 크기 직접 수정
- 실시간 공동 편집
- 결제, 구독, 팀 권한
- 외부 SNS 자동 게시

## 주요 객체

- 작업(`Project`): 하나의 홍보물 제작 단위
- 입력값(`CreativeBrief`): 용도, 크기, 문구, 분위기, 매장 정보, 선택 이미지
- 자산(`Asset`): 메뉴 사진, 참고 디자인 이미지, 생성 이미지, 수정 이미지, 내보내기 파일
- 생성 버전(`GenerationVersion`): 생성 또는 수정으로 만들어진 결과 이미지
- 주석(`Annotation`): 이미지 위에 붙인 포스트잇 메모와 선택 영역
- 내보내기(`ExportJob`): PNG, JPEG, PDF 다운로드 결과

## 사용자 플로우

1. 홈에서 새 작업을 시작한다.
2. 홍보물 용도와 크기를 선택한다.
3. 홍보 문구를 입력한다.
4. 메뉴 사진과 매장 정보를 선택하거나 입력한다.
5. 분위기를 선택하고 참고 디자인 이미지를 선택적으로 업로드한다.
6. 생성 요청을 보낸다.
7. 생성 중 화면에서 진행 상태를 본다.
8. 완성 결과를 확인한다. 결과는 페이드인과 약한 확대 효과로 공개된다.
9. 잘못된 텍스트, 음식 표현, 가격, 배경, 구도 등에 메모를 붙인다.
10. 수정 요청을 보내고 수정 전후를 비교한다.
11. 만족하는 결과를 현재 버전으로 적용한다.
12. 필요한 경우 다른 비율로 재구성한다.
13. PNG, JPEG, PDF 중 원하는 형식으로 다운로드한다.
14. 히스토리에서 이전 버전을 확인하거나 복원한다.

## 홍보물 유형

| 코드 | 이름 | 기본 비율 | 예시 크기 |
| --- | --- | --- | --- |
| `poster` | 매장 포스터 | 4:5 | 1080x1350 |
| `banner` | 가로 배너 | 16:9 | 1920x1080 |
| `menu_board` | 메뉴판 | 3:4 | 1200x1600 |
| `sns_square` | SNS 정사각형 | 1:1 | 1080x1080 |
| `sns_story` | SNS 스토리 | 9:16 | 1080x1920 |
| `x_banner` | X배너 | 1:3 | 600x1800 기준, 생성 요청은 608x1808 |

## 작업 상태

| 상태 | 의미 | 사용자 표시 |
| --- | --- | --- |
| `draft` | 입력 중 | 임시 저장됨 |
| `generating` | 최초 이미지 생성 중 | 이미지를 만들고 있어요 |
| `generated` | 최초 생성 완료 | 결과 확인 |
| `editing` | 수정 이미지 생성 중 | 수정본을 만들고 있어요 |
| `ready` | 적용 가능한 결과 있음 | 다운로드 가능 |
| `exporting` | 파일 변환 중 | 다운로드 파일 준비 중 |
| `failed` | 마지막 작업 실패 | 다시 시도 필요 |

## 성공 기준

- 사용자가 디자인 편집 기능을 학습하지 않고도 첫 홍보물을 생성할 수 있다.
- 실패 시 원인과 재시도 방법이 한국어로 명확히 표시된다.
- 생성, 수정, 재구성, 내보내기 요청은 모두 히스토리에 남는다.
- 프론트엔드는 OpenAI API 키를 전혀 알 수 없다.

## 주요 예외

- 이미지 업로드 실패: 파일 형식, 크기, 네트워크 오류를 구분해 표시한다.
- 생성 실패: OpenAI API 오류, 정책 거절, 서버 오류, 타임아웃을 구분해 저장한다.
- 수정 실패: 선택 영역 없음, 메모 없음, 대상 버전 없음, 이미지 파일 누락을 구분한다.
- 내보내기 실패: 지원하지 않는 형식, 원본 파일 없음, PDF 변환 실패를 구분한다.
- 서버 재시작: DB의 작업 상태와 파일 존재 여부를 기준으로 복구 가능 상태를 판단한다.
