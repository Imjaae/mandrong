# 디자인 시스템

## 방향

만드롱의 UI는 전문 디자인 편집기가 아니라 간단한 제작 도우미처럼 느껴져야 한다. 화면은 조용하고 정갈해야 하며, 사용자가 매 단계에서 해야 할 행동이 하나만 보이도록 구성한다.

## 원칙

- 한 화면에서 한 가지 주요 행동만 제공한다.
- 생성 이미지가 있는 화면에서는 이미지가 가장 큰 요소다.
- 입력 폼은 짧은 섹션으로 나누고 한 번에 많은 설정을 보여주지 않는다.
- 카드 남발을 피하고, 반복 항목이나 모달에만 카드를 사용한다.
- 과도한 그라데이션, 네온, 장식 배경을 사용하지 않는다.
- 텍스트는 모든 화면에서 겹치지 않아야 한다.
- 데스크톱을 우선하되 태블릿과 모바일에서도 핵심 작업이 가능해야 한다.

## 색상

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `color.background` | `#FAFAF7` | 기본 배경 |
| `color.surface` | `#FFFFFF` | 입력 영역, 모달 |
| `color.text` | `#222222` | 기본 텍스트 |
| `color.muted` | `#6F6A62` | 보조 텍스트 |
| `color.line` | `#E6E1D8` | 구분선 |
| `color.primary` | `#2F6F5E` | 주요 버튼 |
| `color.primaryHover` | `#285E50` | 주요 버튼 hover |
| `color.warning` | `#F4C542` | 포스트잇, 주의 |
| `color.danger` | `#C44D42` | 오류 |

단일 색상 계열로만 보이지 않도록 초록, 따뜻한 중립색, 노란 포스트잇 색상을 제한적으로 조합한다.

## 타이포그래피

- 기본 폰트: 시스템 산세리프
- 한글 가독성을 우선한다.
- letter spacing은 0으로 유지한다.
- viewport 너비에 따라 폰트 크기를 직접 스케일하지 않는다.

| 토큰 | 크기 | 행간 | 용도 |
| --- | --- | --- | --- |
| `text.title` | 28px | 1.3 | 화면 제목 |
| `text.section` | 20px | 1.4 | 섹션 제목 |
| `text.body` | 16px | 1.6 | 본문, 입력 |
| `text.caption` | 13px | 1.5 | 보조 설명 |
| `text.button` | 15px | 1.2 | 버튼 |

## 레이아웃

### 데스크톱

- 기본 최대 너비: 1120px
- 입력 중심 화면: 720px 내외
- 결과 화면: 좌측 이미지, 우측 행동 패널
- 화면 상하 여백: 40~64px

### 모바일

- 1열 레이아웃
- 이미지가 먼저 나오고 버튼은 하단에 배치한다.
- 터치 대상 최소 높이는 44px이다.

## 컴포넌트

## 버튼

### 주요 버튼

- 배경: `color.primary`
- 텍스트: 흰색
- 높이: 48px
- radius: 8px 이하
- 비활성 상태는 opacity만 낮추지 말고 배경을 `#B8C7C0`으로 바꾼다.

### 보조 버튼

- 배경: 투명 또는 흰색
- 테두리: `color.line`
- 텍스트: `color.text`

### 아이콘 버튼

- 다운로드, 뒤로가기, 닫기 등 명확한 명령에는 아이콘을 우선 사용한다.
- 사용할 수 있으면 lucide 아이콘을 사용한다.
- 낯선 아이콘에는 tooltip을 제공한다.

## 입력

- label은 항상 표시한다.
- placeholder에만 의미를 의존하지 않는다.
- 오류 메시지는 필드 바로 아래에 표시한다.
- textarea는 최소 120px 높이를 가진다.

## 선택 칩

- 분위기, 용도 선택에 사용한다.
- 선택 상태는 배경색과 테두리로 구분한다.
- 여러 개 선택 가능한 칩은 체크 아이콘을 함께 표시한다.

## 이미지 미리보기

- 결과 이미지는 별도 장식 카드 안에 넣지 않는다.
- 배경과 구분이 필요할 때만 얇은 테두리를 사용한다.
- 로딩 중에는 같은 비율의 스켈레톤을 유지해 레이아웃 흔들림을 막는다.

## 포스트잇 메모

- 기본 색상: `#F4C542`
- 보조 색상: `#F8E08E`, `#F2B8A2`
- radius: 6px
- 그림자는 약하게 사용한다.
- 메모는 이미지 위에 표시되지만 최종 생성 이미지에는 포함되지 않는다는 점을 UI에서 간단히 안내한다.

## 애니메이션

### 결과 공개

```css
.result-reveal {
  opacity: 0;
  transform: scale(0.985);
  animation: resultReveal 280ms ease-out forwards;
}

@keyframes resultReveal {
  to {
    opacity: 1;
    transform: scale(1);
  }
}
```

### 제한

- 반복되는 장식 애니메이션은 사용하지 않는다.
- 화면 전환 애니메이션은 200ms 이하로 유지한다.
- 생성 결과 공개 애니메이션만 제품 경험의 핵심 애니메이션으로 둔다.

## 한국어 문구 톤

- 짧고 직접적으로 쓴다.
- 실패 메시지는 원인과 다음 행동을 함께 제시한다.
- 전문 용어 대신 사용자가 이해하기 쉬운 말을 쓴다.

예시:

- `홍보물을 만들고 있어요`
- `수정할 내용을 메모로 남겨주세요`
- `이미지 파일을 찾지 못했어요`
- `다시 시도`
- `수정본 적용`
