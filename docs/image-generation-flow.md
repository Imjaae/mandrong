# 이미지 생성 흐름

## 목표

사용자가 입력한 용도, 크기, 문구, 메뉴 사진, 매장 정보, 분위기, 참고 이미지를 바탕으로 `gpt-image-2`가 완성형 홍보 이미지를 생성한다.

프론트엔드는 생성 요청과 상태 조회만 담당한다. 프롬프트 조립, OpenAI API 호출, 결과 파일 저장은 모두 FastAPI 서버에서 수행한다.

## 최초 생성 단계

1. 사용자가 입력을 완료하고 `홍보물 만들기`를 누른다.
2. Web은 `POST /projects/{project_id}/generations`를 호출한다.
3. API는 프로젝트, 브리프, 선택 자산을 조회한다.
4. API는 `generation_jobs`에 `queued` 작업을 생성한다.
5. API는 프로젝트 상태를 `generating`으로 변경한다.
6. 백그라운드 작업이 시작되면 작업 상태를 `running`으로 변경한다.
7. API는 서버 내부에서 최종 프롬프트를 만든다.
8. API는 OpenAI `gpt-image-2`에 이미지 생성 요청을 보낸다.
9. 응답 이미지를 `storage/generated`에 저장한다.
10. `assets`에 `generated_image`를 생성한다.
11. `generation_versions`에 새 버전을 생성한다.
12. 프로젝트 상태를 `ready`, `current_version_id`를 새 버전으로 변경한다.
13. 작업 상태를 `succeeded`로 변경한다.

## 프롬프트 구성

프롬프트는 서버에서 다음 섹션을 순서대로 조립한다.

### 1. 역할

요식업 홍보물 전문 디자이너로서 완성형 이미지를 만든다고 지시한다.

### 2. 출력 형식

- 홍보물 유형
- 정확한 가로/세로 크기
- 가로/세로 크기는 `gpt-image-2` 제약에 맞춰 각각 16의 배수여야 한다.
- 최종 이미지는 바로 게시 가능한 완성본
- 별도의 편집 안내 문구나 설명 문구를 이미지에 넣지 않음

### 3. 필수 포함 정보

- 사용자가 한 번에 입력한 전체 홍보 문구
- 매장명
- 메뉴명
- 연락처 또는 주문 방법

### 4. 이미지 내용

- 제공된 메뉴 사진이 있으면 음식을 자연스럽게 중심 소재로 사용
- 음식이 실제보다 과장되거나 다른 메뉴로 바뀌지 않도록 지시
- 참고 디자인 이미지는 분위기와 구성 참고로만 사용

### 5. 스타일

- 선택된 분위기 키워드
- 자유 분위기 설명
- 과도한 네온, 복잡한 장식, 읽기 어려운 글자 금지
- 한글 텍스트가 정확하고 잘 읽히도록 지시

### 6. 제약

- 가격, 전화번호, 매장명 등 텍스트를 임의 변경하지 않음
- 오탈자를 만들지 않음
- 메뉴 사진에 없는 브랜드 로고나 상표를 만들지 않음
- 음식을 혐오스럽거나 비위생적으로 표현하지 않음

## 요청 페이로드 저장

`generation_jobs.request_payload`에는 OpenAI 원본 응답 전체가 아니라 다음 요약 정보를 저장한다.

```json
{
  "model": "gpt-image-2",
  "purpose": "poster",
  "width": 1080,
  "height": 1350,
  "menu_asset_ids": ["uuid"],
  "reference_asset_ids": ["uuid"],
  "brief_revision": "2026-08-02T00:00:00Z"
}
```

## 상태 폴링

Web은 `GET /generation-jobs/{job_id}`를 2초 간격으로 조회한다.

- `queued`: 대기 문구 유지
- `running`: 생성 중 문구 유지
- `succeeded`: 결과 화면으로 이동
- `failed`: 오류 화면 표시
- `cancelled`: 취소됨 표시

MVP에서는 서버 센트 이벤트나 웹소켓을 사용하지 않는다. 추후 긴 작업이 많아지면 SSE로 교체할 수 있다.

## 실패 처리

| 원인 | 저장 코드 | 사용자 메시지 | 재시도 |
| --- | --- | --- | --- |
| OpenAI 일시 오류 | `OPENAI_TEMPORARY_ERROR` | 잠시 후 다시 시도해주세요 | 가능 |
| 정책 거절 | `OPENAI_POLICY_BLOCKED` | 이 요청은 이미지로 만들 수 없어요 | 입력 수정 필요 |
| 타임아웃 | `GENERATION_TIMEOUT` | 생성 시간이 너무 오래 걸렸어요 | 가능 |
| 파일 누락 | `SOURCE_ASSET_MISSING` | 선택한 사진을 찾지 못했어요 | 파일 재업로드 필요 |
| 서버 오류 | `GENERATION_FAILED` | 이미지 생성에 실패했어요 | 가능 |

실패 시 `generation_jobs.status = failed`, `projects.status = failed`로 저장한다. 실패한 작업의 프롬프트와 오류 메시지는 개발자 디버깅용으로 DB에 남기되 OpenAI API 키나 민감 정보는 저장하지 않는다.

## 결과 이미지 저장

- 파일 확장자는 실제 MIME 타입에 맞춘다.
- 파일명은 `{project_id}/{version_id}.png` 형태를 기본으로 한다.
- 동일 버전의 이미지 파일은 덮어쓰지 않는다.
- 저장 후 이미지 크기와 파일 크기를 다시 읽어 DB에 기록한다.

## 프론트엔드 표시

- 최초 로딩 화면은 빈 캔버스와 스켈레톤을 보여준다.
- 생성 완료 후 이미지는 페이드인과 약한 확대 효과로 표시한다.
- 생성 결과 위에는 텍스트 안내를 겹치지 않는다.
- 오류는 이미지 영역 아래에 간결하게 표시한다.
