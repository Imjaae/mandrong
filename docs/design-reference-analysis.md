# 디자인 참고 분석

## 목적

첨부된 참고 이미지는 만드롱 UI의 직접적인 복제 대상이 아니다. 브랜드, 로고, 서비스명, 문구, 아이콘 조합, 회의록 관련 기능은 사용하지 않는다. 만드롱에는 색감, 여백, 정보 위계, 버튼 크기, 이미지 배치, 전체적인 정돈감만 해석해서 적용한다.

## 참고 이미지에서 관찰한 구조

### 전체 레이아웃

- 화면은 좌측 고정 사이드바와 우측 넓은 작업 영역으로 나뉜다.
- 상단에는 얇은 헤더가 있으며, 주요 전역 액션과 언어/알림 같은 보조 액션이 오른쪽에 배치된다.
- 본문 영역은 대부분 비워두고, 핵심 행동 묶음만 중앙에 배치한다.
- 좌측 사이드바는 탐색과 최근 항목을 담당하고, 중앙 본문은 현재 해야 할 행동 하나에 집중한다.

### 정보 위계

- 가장 강한 시각 요소는 중앙의 핵심 메시지와 주요 CTA 버튼이다.
- 보조 태그는 CTA보다 위에 있지만 작은 크기와 낮은 대비로 보조 역할만 한다.
- 사이드바의 목록은 촘촘하지만, 구분선과 작은 상태 배지로 정돈되어 있다.
- 화면 전체에서 사용자 시선은 `사이드바 탐색 -> 중앙 주요 행동 -> 상단 보조 액션` 순서로 이동한다.

### 여백

- 중앙 콘텐츠 주변에 매우 넓은 빈 공간이 있다.
- 여백은 장식이 아니라 사용자가 다음 행동을 쉽게 판단하도록 만드는 장치로 쓰인다.
- 좌측 사이드바는 상대적으로 밀도가 높고, 본문은 매우 낮은 밀도를 가진다.
- 사이드바와 본문 사이에는 명확한 세로 구분선이 있다.

### 색감

- 배경은 거의 흰색에 가까운 밝은 회색이다.
- 표면과 입력 요소는 흰색이며 얇은 회색 테두리로 구분된다.
- 강조색은 선명한 핑크 계열 하나가 주요 버튼과 활성 상태에 집중적으로 쓰인다.
- 보조 배지는 연한 배경과 작은 텍스트로 처리되어 시각적 무게가 낮다.
- 전체적으로 높은 채도의 색은 매우 제한적으로 사용된다.

### 버튼

- 주요 CTA는 크고 넓으며, 약한 그림자를 가진다.
- radius는 둥글지만 과도하지 않다.
- 주요 버튼에는 아이콘과 텍스트가 함께 있어 행동이 빠르게 인식된다.
- 보조 버튼은 흰색 배경, 얇은 테두리, 작은 크기로 처리된다.

### 목록과 상태

- 좌측 목록의 각 항목은 제목, 상태 배지, 날짜로 구성된다.
- 상태 배지는 매우 작고 둥근 pill 형태다.
- 진행 중 상태는 강조색 계열로, 완료 상태는 무채색 계열로 구분된다.
- 목록 항목 사이에는 여백보다 얇은 구분선을 사용해 밀도는 유지하되 혼잡함을 줄인다.

## 만드롱에 적용할 원칙

## 1. 생성 결과 중심의 작업 무대

만드롱의 결과 화면, 히스토리 화면, 메모 수정 화면은 넓은 본문 작업 영역을 사용한다. 생성된 홍보물 이미지는 본문 중앙 또는 좌측 큰 영역에 배치하고, 조작 버튼은 오른쪽 좁은 패널에 둔다.

적용:

- 결과 이미지 영역은 화면에서 가장 큰 면적을 차지한다.
- 이미지 주변은 충분히 비워둔다.
- 이미지 위에는 불필요한 설명 문구를 겹치지 않는다.
- 다운로드, 수정, 비율 재구성 같은 행동은 한 패널에 정리한다.

## 2. 단계 입력 화면의 중앙 집중

새 작업 생성 단계에서는 사이드바보다 중앙 집중형 화면을 우선한다. 참고 이미지의 중앙 CTA 구조를 가져오되, 만드롱에서는 `용도 선택`, `문구 입력`, `사진 선택`, `분위기 선택` 같은 한 단계 입력에 적용한다.

적용:

- 각 단계의 제목은 짧고 명확하게 쓴다.
- 입력 영역 최대 너비는 720px 안팎으로 제한한다.
- 한 화면에 너무 많은 선택지를 넣지 않는다.
- 다음 버튼은 하단 우측에 일정한 크기로 배치한다.

## 3. 히스토리와 프로젝트 목록의 정돈감

참고 이미지의 사이드바 목록 구조는 만드롱의 최근 작업, 히스토리, 버전 목록에 적용한다.

적용:

- 작업 제목, 상태, 생성일을 한 줄 그룹으로 묶는다.
- 상태는 작은 pill 배지로 표시한다.
- 현재 적용 버전은 강조색 배지로 표시한다.
- 완료된 내보내기나 이전 버전은 무채색 배지를 사용한다.

## 4. 제한적인 강조색

만드롱의 기존 디자인 시스템은 초록 계열을 주요색으로 정의했다. 참고 이미지의 핑크를 복사하지 않고, 동일한 방식으로 “강조색을 제한적으로 쓰는 방식”만 반영한다.

적용:

- `color.primary`는 주요 CTA, 선택 상태, 현재 버전에만 사용한다.
- 넓은 배경에 강조색을 많이 깔지 않는다.
- 오류, 경고, 포스트잇 색상은 주요 CTA 색과 경쟁하지 않게 분리한다.
- 버튼 그림자는 약하게 사용하고, 색 그림자는 남발하지 않는다.

## 5. 얇은 경계와 조용한 표면

참고 이미지의 입력창, 사이드바, 헤더는 얇은 선과 흰 표면으로 구분된다. 만드롱도 복잡한 카드 장식 대신 경계선과 여백으로 화면을 정리한다.

적용:

- 헤더, 사이드 패널, 입력 묶음에는 `color.line` 1px 경계선을 사용한다.
- 반복 카드에는 8px 이하 radius를 사용한다.
- 카드 안에 카드를 넣지 않는다.
- 페이지 섹션 자체를 떠 있는 카드처럼 만들지 않는다.

## 만드롱 화면별 적용

## 홈

- 좌측 사이드바형 최근 작업 목록을 선택적으로 도입할 수 있다.
- 첫 화면의 중심은 `새 홍보물 만들기` 버튼이다.
- 최근 작업이 많아져도 본문 중앙 CTA가 묻히지 않게 한다.

## 새 작업 생성

- 중앙 집중형 단계 화면을 유지한다.
- 상단에는 현재 단계만 간단히 표시한다.
- 선택지는 큰 카드보다 얇은 경계의 리스트 또는 칩 형태를 우선한다.

## 결과 확인

- 생성 이미지를 큰 작업 무대로 배치한다.
- 우측 패널에는 `메모로 수정`, `다른 비율로 만들기`, `다운로드`, `히스토리`만 둔다.
- 버튼은 같은 높이로 정렬하고, 주요 행동 하나만 채움 버튼으로 표시한다.

## 메모 수정

- 이미지 작업 영역은 최대한 크게 유지한다.
- 포스트잇 메모 목록은 사이드바처럼 정돈된 세로 목록으로 둔다.
- 포스트잇 색은 노란색 계열을 사용하되, 최종 이미지에는 포함되지 않음을 명확히 한다.

## 히스토리

- 버전 목록은 이미지 썸네일 중심으로 보여준다.
- 상태와 날짜는 작게 표시한다.
- 현재 적용 버전만 시각적으로 강하게 표시한다.

## 적용하지 않을 것

- 참고 이미지의 브랜드명, 로고, 문구, 회의록 기능
- 핑크 색상 체계의 직접 복사
- 회의 목록 구조를 그대로 복제한 사이드바
- 알림, 언어 선택, 크레딧 버튼 같은 만드롱 MVP와 무관한 전역 기능
- 중앙 브랜드 로고 노출 구조

## 구현 체크리스트

- 주요 CTA 높이는 48px 이상으로 유지한다.
- 보조 버튼은 흰색 배경과 얇은 테두리로 처리한다.
- 본문 배경은 밝은 중립색으로 유지한다.
- 이미지 결과 화면은 좌우 여백보다 이미지 면적을 우선한다.
- 상태 배지는 작고 조용하게 만든다.
- 화면당 주요 행동은 하나만 채움 버튼으로 둔다.
- 브랜드와 문구는 만드롱 고유 문구만 사용한다.
